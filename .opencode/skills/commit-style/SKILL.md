# Commit style

Write every commit message in English, following these rules:

- Use the imperative mood ("Add delete command", not "Added" or "Adds").
- Keep the subject line under 60 characters.
- Do not end the subject line with a period.
- Optionally add a body after a blank line explaining why the change was made.
