# AGENTS.md

Консольний трекер звичок на Python: add/done/list/delete, дані в `habits.db` (SQLite). Тільки stdlib.

## Запуск
`python main.py add "Назва"` · `python main.py done <id>` · `python main.py list` · `python main.py delete <id> [--yes]`

## Тести
`python -m unittest`

## Стиль
Docstring-и та UI-тексти — українською; коміти — англійською; зовнішніх залежностей не додавати.
