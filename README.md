# Habit Tracker

Консольний трекер звичок на Python без зовнішніх залежностей. Звички та дати
виконання зберігаються у `habits.json`, для кожної звички показується серія
днів поспіль.

## Запуск

Додати звичку:

```console
python main.py add "Читання"
```

Відмітити виконання за сьогодні (ID видно у `list`):

```console
python main.py done 1
```

Видалити звичку (запитає підтвердження, типова відповідь — `N`):

```console
python main.py delete 2
```

Пропустити підтвердження можна прапорцем `--yes`:

```console
python main.py delete 2 --yes
```

Показати звички та серії:

```console
python main.py list
```

Приклад виводу:

```text
1. [x] Читання — серія: 3 дн.
2. [ ] Спорт — серія: 0 дн.
```

`[x]` — сьогодні вже відмічено, `[ ]` — ще ні. Повторний `done` за той самий
день дубліката не створює.

## Тести

```console
python -m unittest
```

Тести не торкаються реального `habits.json`: файл для перевірок створюється
у тимчасовій теці.

## Формат даних

`habits.json` створюється автоматично при першому `add` і має вигляд:

```json
{
  "habits": [
    {
      "id": 1,
      "name": "Читання",
      "created": "2026-11-07",
      "dates": ["2026-11-06", "2026-11-07"]
    }
  ]
}
```

- `id` — ціле число, унікальне в межах файлу;
- `name` — назва звички;
- `created` — дата створення (`YYYY-MM-DD`);
- `dates` — відмічені дні виконання (`YYYY-MM-DD`).

`habits.json` доданий у `.gitignore`, бо це локальні дані.

## Правило серії

Серія рахується назад від сьогодні, якщо сьогодні вже відмічено. Якщо
сьогодні ще не відмічено, відлік іде від учора — щоб поточна серія не
обнулялася зранку. Якщо немає ні сьогоднішньої, ні вчорашньої відмітки,
серія дорівнює 0.
